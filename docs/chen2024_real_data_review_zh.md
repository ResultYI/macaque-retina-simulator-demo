审查代理 `/root/contract_review` 独立只读核对真实 MAT、README、固定模型、官方论文和历史仓库目录。未改变参数、裁剪数据、执行包内代码或新增实验。本次检查限于单位、时间对齐、归一化、输入可用性与数据泄漏。

结论：可完成真实数据清点和原曲线展示，不能声称来源数据复现成功或给出可比模型 RMSE；当前停止判断正确。

- MAT 与 README 的字节数、官方 SHA256 均匹配。六条记录均为两个字段、各 80,000 个有限 double 样本。逐记录刺激值相同，每条 1,026 个负值、12,538 个值 ≥50,000 R*/s。
- README 明确 dt=0.1 ms、刺激 R*/s、响应按饱和闪光估计的暗电流归一化、4–5 次重复平均；没有提供负值修正、裁剪、预适应历史或逐细胞参数。
- 勘误：Fig.3/4 和无 hard cap 的作者 kernel 表明 ≥50k 点数不能单独证明数据不可复现。p15 的 <50k 是不含漂白/限制曝光情境的适用性讨论，不是瞬时拒绝条件；也未定义可机械替代的全段均值上限。负值处理和时间/前史依据仍未找到。
- 原论文 p5/p19 的逐 cell 暗电流/G_D 与 gamma 设置属于作者拟合流程，当前指令禁止重拟合、调 gain，不能借该流程补造本次缺失值。
- README 的 dt 与等长成对字段足以构造 0–7.9999 s 的相对样本网格，未知的是实验起点、预刺激历史与源 kernel 相位对齐，不能优化时间平移。
- 缺逐 cell 暗电流阻止恢复真实 pA 与逐 cell G_D，但固定模型电流除以自身暗电流幅值可以定义无量纲预测；该缺失本身不阻止所有归一化比较。本次真正阻断条件仍是未解释的负刺激及历史/相位依据缺失。
