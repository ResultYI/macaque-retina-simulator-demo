# 猕猴视网膜模拟器 中文操作手册

适用版本：2026年10月12日的本地项目 `D:\macaque_retina_simulator`。

这份手册说明如何查看已有结果、导入媒体、设置小ROI运行、选择细胞和导出记录。首次使用建议直接载入昨夜结果，无需重新积分。程序是Windows桌面工具；手册可在手机阅读，GUI本身仍在电脑上操作。

## 1 最快上手查看昨夜结果

### 一个可以直接照做的完整流程

1. 在文件资源管理器打开 `D:\macaque_retina_simulator`，双击 `run_retina_gui.cmd`。
2. 在窗口左上方点击“载入结果”。这是选择文件夹的对话框。
3. 按下面顺序进入文件夹，选择最后一行的运行目录。不要选它的父目录，也不要选 `windows` 子目录。

```text
D:\macaque_retina_simulator\
reports\background_preparation_runs\
20261011T170043172502Z\run\
20261011T170043213842Z_8b6efb04
```

上述换行仅为阅读；各行表示依次进入的文件夹。完整结果目录中应同时有 `manifest.json`、`summary.json` 和 `windows` 文件夹。

4. 等待“结果已载入”状态出现。在右侧顶部的层下拉框选择 `midget_RGC_ON`，输出下拉框选择 `midget_RGC_ON.voltage`。
5. 将范围选为 `owner`、类型选为“全部类型”；坐标可选 `RF`。将“窗口”设为 `9`，查看第10个、也是最后一个窗口。
6. 在空间散点图上单击一个点。下方显示该细胞ID和当前窗口的电位曲线。点击“导出所选曲线”，选择一个新的CSV文件名，即可导出该细胞跨已完成窗口的历史。

**查看结果无需点击“运行”。** 载入结果读取现成记录；点击“运行”会开始一条新轨迹，重新构建并进行背景准备。

### 昨夜例子的实际范围

该实例是来源受限的二维小ROI及halo，执行34组件、20个必需机制层。均匀背景准备1.3秒达到既定数值条件，随后连续记录20毫秒刺激，共10个2毫秒窗口；整个任务实际用时109.65分钟。它不是实时模拟，也不是全眼模型。

刺激记录使用绝对时间轴，范围约为 `1.300 至 1.320 s`；窗口编号从0开始，因此0到9对应10个窗口。已有完整owner曲线有21个唯一采样时刻。数值收敛不代表生理验证。

## 2 启动与界面区域

### 启动入口

推荐入口是项目根目录的 `run_retina_gui.cmd`。它默认使用以下已配置的Python环境：

```text
<USER_HOME>\anaconda3\envs\
retipath_v1\python.exe
```

启动脚本会切换到项目目录，无需手动安装或升级环境。如果提示 `Python not found`，检查该环境路径是否存在；不要为了启动随意更换研究环境。

### 窗口中的四个区域

- **左上媒体区**：“导入图像 / 视频”“载入结果”，以及输入画面预览。视频预览滑块只改变预览时刻。
- **左侧设置区**：可滚动的参数列表，底部有“保存配置”“载入配置”；列表内有“眼位轨迹 CSV”的“选择 / 清除”和“HC 几何 JSON”。
- **右侧结果区**：层、输出、细胞类型下拉框；坐标、owner/halo范围、色标、窗口和“跟随”；空间图、细胞ID及曲线。
- **底部控制区**：“运行”“暂停”“继续”“停止”，进度、模拟时间和一行状态。错误也显示在状态行。

窗口最低尺寸为1080×680；小屏幕可先最大化窗口，再滚动左侧参数。不是每个输出都提供所有坐标选项，坐标下拉框以当前记录实际保存的几何为准。

### 配置与结果分别是什么

“载入配置”选择一个JSON文件，只恢复运行参数和可访问的媒体输入；它不会加载已计算状态。“载入结果”选择一个完整运行目录，用于查看保存的数据。

昨夜完整准备的配置是前述运行目录中的 `config.json`。载入这个配置后再点击“运行”，会重新进行完整背景准备，可能再次耗时约两小时；配置文件不是缓存。

## 3 导入图片视频与指定眼位

### 图片和视频

点击“导入图像 / 视频”，选择实际文件。对话框列出的图片扩展名为PNG、JPG、JPEG、BMP、TIF、TIFF；视频为MP4、AVI、MOV、MKV、WEBM。能否读取仍取决于图片内容或当前OpenCV解码器，扩展名不保证可解码。

图片按静态RGB画面使用。视频必须有有效的FPS、帧数和尺寸；“开始 / s”与“记录 / s”相加不得超过视频长度。当前视频按恒定FPS选帧，不支持可变FPS时间轴的专门重采样。视频预览滑块不会自动修改“开始 / s”。

本版GUI没有“生成闪光”“生成光栅”等内置刺激按钮。可以导入事先保存好的图片或视频。昨夜使用的现成均匀灰色PNG位于：

```text
项目根目录\reports\hc_acceptance\
20261011T100207621130Z\
engineering_uniform_rgb.png
```

媒体的RGB被转换为具名的工程光输入近似。它不是显示器、光谱或视网膜光量的物理标定结果；不要通过任意调整背景值把普通图片称为已校准刺激。

### 固定眼位与CSV

没有CSV时，使用“固定眼位 x / °”“固定眼位 y / °”，默认均为0。

需要指定眼位时，在“眼位轨迹 CSV”旁点击“选择 / 清除”，选择UTF-8 CSV。已经选过文件时，再点击一次会清除该文件并恢复固定眼位；需要换文件时，清除后再次选择。

CSV必须至少有两行有限数值，包含下面三个列名，时间严格递增，并覆盖刺激时间0到“记录 / s”的结束时刻。CSV时间不包含背景准备，也不是视频源文件的绝对时刻。

```csv
time_seconds,x_deg,y_deg
0.000,0,0
0.020,0,0
```

这是固定眼位的格式示例，覆盖20毫秒记录；若记录更长，应相应延长末行时间。程序在线性插值后使用这些指定眼位，不会替你生成眼动模型或下一注视点。

## 4 关键设置默认值与计算开销

### 保持默认研究原型

新界面的“运行模式”默认是“研究原型”，对应 `retina_contact_geometry_effective_v1`。首次操作保持该模式及其成套几何配置。

| 设置 | 当前默认值 | 含义 |
|---|---|---|
| 目标位置 | 自定位置 | 由下方ROI参数确定 |
| HC 空间模式 | 联合HC合成 | 该研究原型使用的HC布局 |
| HC arbor 来源 | W2000_equal_area_bounded_edges_047_104 | 有限arbor来源及明确的近似适用域 |
| IPL 几何 | retina_contact_geometry_effective_v1 | 成套的typed IPL几何 |
| owner 输出 | midget_RGC_ON | 所请求的目标ROI输出 |
| H1 arbor / mm、H2 arbor / mm | 留空 | 默认来源配置提供footprint，留空不是半径为0 |
| 输入 adapter | contrast_reference_v1 | 工程RGB对比映射 |
| reference u / linear | 0.5 | 线性RGB参考强度，无量纲 |

“源约束混合”“工程预览”用于其他或历史配置。几何与输入设置有组合约束；不要只改一个模式名称就把旧配置称为已校准。`HC 几何 JSON` 是高级来源配置入口，普通操作保持现成配置即可。

### 时间和空间参数

| 界面字段 | 新界面默认值 | 单位与用途 |
|---|---:|---|
| 开始 / s | 0 | 媒体源中的起始时刻 |
| 记录 / s | 0.006 | 刺激记录长度，6ms |
| 背景预运行 / s | 0.002 | 固定模式的2ms预运行，不保证稳态 |
| 背景初始化 | fixed_prerun | 固定预运行模式 |
| 适应上限 / s | 10 | bounded模式的最大模拟准备时间 |
| 窗口 / s | 0.002 | 每个保存窗口2ms |
| 采样间隔 / s | 0.001 | 输出记录间隔1ms，不是solver步长 |
| ROI 中心 x / mm | 0.35 | RF坐标中的中心位置 |
| ROI 中心 y / mm | 0 | RF坐标中的中心位置 |
| ROI 宽 / mm、ROI 高 / mm | 各0.02 | 20µm×20µm目标ROI |
| halo / mm | 0.04 | 40µm外部计算支持区域 |
| 视场宽 / ° | 70 | 输入画面映射宽度，非模拟的全眼范围 |
| 固定眼位 x / °、y / ° | 各0 | 人工指定眼位 |
| 种子 | 20261010 | 非负整数，参与布局和随机状态复现 |

时间设置中的记录、预运行、窗口、采样间隔及适应上限须为0.1ms的整数倍；采样间隔不能大于窗口长度。1秒=1000毫秒，1毫米=1000微米。

“preview cone 数”“preview rod 数”默认64、96，仅表示工程预览的有效采样设置；它们不是默认研究ROI中的真实生成数量。来源受限ROI按其密度和几何生成，预算不足会报错，不能靠改这两个数偷偷稀释来源密度。新配置中的 `max_spatial_cells` 默认为60000，该预算未单独列为GUI字段。

### 光背景单位

| 字段 | 默认值 | 单位 |
|---|---:|---|
| native 背景 / td | 100 | native模型的td输入 |
| cone 背景 / R*/s | 1000 | 物理cone参考输入的R*/s |
| rod 背景 / R*/s | 5 | rod输入的R*/s |

R*/s表示单位时间的光异构化率，不能直接换成屏幕亮度。中央研究ROI没有适用的Chen外围LM物理支路，因此声明的physical-cone背景并不表示这个支路在本次中央实例执行了。

### 为什么几毫秒的记录也可能很慢

新界面的固定2ms预运行加6ms记录只是一段短工程运行，也需要构建大量细胞、接触、状态和元数据。扩大ROI、halo、记录长度或减小采样间隔会增加开销。

昨夜同一小ROI生成6102个cone和7804个active HC几何节点，记录77个状态数组。完整背景准备实际耗时104.08分钟，加上构建、20ms刺激及保存，总计109.65分钟。不能把“记录 / s”的数值当作等待的墙钟时间。

## 5 运行暂停继续与停止

### 运行一段新的短记录

1. 启动程序，保持默认“研究原型”。
2. 点击“导入图像 / 视频”，选择可读取的文件，确认预览和媒体信息出现。
3. 首次短跑保持记录0.006s、固定背景预运行0.002s、窗口0.002s、采样0.001s，以及默认ROI和几何。
4. 如需保存这些参数，点击“保存配置”，选择JSON文件。保存前也会校验输入和参数。
5. 点击“运行”，观察“构建中”“运行中”或错误状态。已完成窗口会逐步出现。

这条短跑流程依据当前代码核对；本轮没有重新通过真实GUI执行一条新积分。固定预运行不会判定全网背景收敛。

### 控制按钮的实际语义

| 按钮 | 作用 |
|---|---|
| 运行 | 新建任务和结果目录，从新初始化状态开始计算 |
| 暂停 | 请求在后台安全边界暂停，可能要等当前计算段完成 |
| 继续 | 恢复这个仍存在的、已暂停的任务，保持其内存状态 |
| 停止 | 取消本次任务，在安全边界结束；保留已经完成的窗口及有效checkpoint |

界面没有名为“取消”的独立按钮，取消任务使用“停止”。请求后若显示“等待当前窗口完成后暂停”或“停止中”，先等待后台响应；不需要反复点击“运行”。构建和长计算段内可能无法立即响应。运行时不能替换媒体或配置。

**磁盘上的prepared checkpoint目前不能通过GUI复用。** “继续”只对当前还活着的暂停任务有效；关闭窗口、结束任务或重新启动程序后，不能用这个按钮续算。底层有restore API，但现成GUI和CLI入口均未接入从磁盘checkpoint启动的流程。

### 完整数值背景准备

`bounded_convergence` 会从声明的均匀背景按既定标准准备；“适应上限 / s”是模拟时间上限，不保证一定收敛。默认独立墙钟预算是60秒，未单独提供GUI输入框；达到预算可能给出NOT_REACHED。

昨夜 `config.json` 已保存 `bounded_convergence`、10秒模拟上限、7200秒墙钟预算，以及“必须收敛才进行刺激”的配置。加载它会恢复这些设置。再次点击“运行”仍会重新计算背景，不能自动读取昨夜prepared状态。

CONVERGED表示本次既定数值准备标准通过；NOT_REACHED表示相应条件尚未达到。使用“必须收敛”的配置时，未达到条件就不运行后续刺激。查看实际结果时以 `background_initialization.json` 和 `summary.json` 为准。

## 6 逐层选择细胞曲线与单位

### 选择一个记录对象

先选层，再选具体输出端口；端口名称是保存的真实标识，例如 `midget_RGC_ON.voltage`。然后按需要选细胞类型、坐标和范围，单击空间图中的点。

`owner`是目标ROI中的对象，`halo`是参与计算的外部支持对象。“全部”显示两者。默认研究实例保留halo以支持连接，不应把halo数据全部解释为目标ROI的直接输出。

某些端口表示“接点”，不是细胞。界面会按实际元数据提供OPL或IPL接触位置；不要把接点坐标称为胞体坐标。

### 坐标与色标

- `RF`：感受野或输入采样位置。
- `Soma`：记录中实际提供的解剖胞体位置。
- `OPL`、`IPL`：相应层中的末端、树突或接触位置，具体语义以输出元数据为准。

不要把不同坐标框架当成同一套坐标。下拉框只列出当前端口保存的框架。

“色标”选“自动”时按当前显示数据调整；跨窗口比较同一输出可选“固定”，在两个数值框输入合理的最小值、最大值，按回车刷新。颜色变化不一定意味着数值按同样比例变化。

### 时间曲线与窗口

“窗口”选择某个已保存区间，编号从0开始。“跟随”让正在运行的视图跟随最新完成窗口；手动切换窗口会关闭跟随。

**GUI下方曲线显示当前窗口，CSV导出读取跨已完成窗口的历史。** 对单个窗口的汇总量，GUI可能只显示一个端点；这不是数据丢失。

### 正确解释数值

以端口显示和CSV表头中的单位为准。RGC `voltage` 使用V，`-0.0547 V`约为`-54.7 mV`。native模型标为 `vH_native_voltage` 的量不能直接当成mV；无量纲释放代理也不是已标定的递质浓度。

窗口汇总spike计数表示该窗口内的计数，不是每个采样时刻的瞬时发放率。出现Hz单位的条件事件率也不能自动等同于经过独立动物验证的生理平均发放率。

昨夜owner中有midget ON/OFF各25个、S-ON 1个，parasol ON/OFF各0个。选择parasol的owner范围可能为空；可切回“全部”或“halo”查看已有对象，不必为了一个空图重新计算或随意扩大ROI。

## 7 导出格式与文件位置

### 三个导出按钮

| 按钮 | 输出 | 使用要点 |
|---|---|---|
| 导出所选曲线 | CSV | 先选择细胞或接点；包含时间、数值及单位、cell_id、meaning、profile |
| 导出当前图 | PNG | 当前空间图与当前窗口曲线的组合图，不是完整GUI屏幕截图 |
| 导出结果包 | 完整运行目录副本 | 先暂停或结束任务，再选择原目录外的目标文件夹 |

CSV使用UTF-8 BOM。连续端口的时间列为 `time_seconds`；窗口汇总量为 `window_end_seconds`。采样时间保留绝对模拟时间，背景准备不作为媒体记录窗口写入。

CSV和PNG导出不覆盖已有同名文件；结果包也要求目标运行子目录尚不存在。导出包会复制元数据、已保存窗口和checkpoint，可能较大，不能放在原运行目录内部。配置JSON由“保存配置”单独保存，不等于结果包或续算缓存。

### 常规GUI运行保存在哪里

普通新GUI任务默认写入：

```text
D:\macaque_retina_simulator\reports\
platform_runs\<UTC时间戳_短ID>\
```

昨夜的授权完整背景示例使用手册第1节给出的特殊运行目录，仍可通过同一个“载入结果”按钮查看。

| 文件或文件夹 | 用途 |
|---|---|
| config.json | 运行参数和媒体路径 |
| manifest.json、resolved_profile.json | 实际组件、输入、单位、几何与来源元数据 |
| windows\*.npz | 每个完成窗口的真实记录 |
| summary.json、status.json | 最终状态、模拟时长和运行信息 |
| background_initialization.json | 实际背景准备时长、条件及残差 |
| initial_checkpoint.json | 新初始化状态 |
| prepared_checkpoint.json | 背景准备结束时状态 |
| latest_checkpoint.json、final_checkpoint.json | 最新及最终轨迹状态，可能已经处于刺激阶段 |

不是每种运行模式都生成背景专用文件。不要只拿一个NPZ或checkpoint文件去“载入结果”；该按钮需要完整目录。

## 8 常见问题与当前限制

### 常见问题

**载入结果失败。** 确认选的是同时包含 `manifest.json` 和 `windows` 的末级目录。大型元数据首次读取可能需要等待。若原媒体被移动，已有记录和输入预览是两件事，应先核对文件路径。

**“运行”不可用或提示先导入媒体。** 新运行需要一张实际图片或可解码视频；只填写参数不够。正在运行时也不能新开第二个任务。

**视频时间段超出长度。** 使“开始 / s”加“记录 / s”不超过视频时长。预览到某一帧不会自动修改这两个参数。

**输入时间被拒绝。** 检查是否是0.0001秒的整数倍，采样是否超过窗口；默认0.006、0.002、0.001均符合约束。

**看不到曲线或点很少。** 先确认选了有记录的输出和窗口，再检查类型及owner/halo过滤；需要在散点图中选点才显示所选对象曲线。一个汇总量可能只显示一个端点。

**暂停或停止没有立即完成。** 后台在安全边界响应。先看底部状态，不要重复启动新任务。关闭运行中的窗口也会请求停止，不会留下可通过“继续”跨重启恢复的任务。

**背景NOT_REACHED。** 可能达到模拟、墙钟或观察预算，也可能尚未满足条件。它不能改称稳态。昨夜完整实例需要1.3秒数值准备、104.08分钟背景墙钟时间；默认60秒墙钟预算不足以保证同样结果。

**导出提示文件已存在。** 改用新的CSV/PNG文件名，或选择新的结果包子目录。运行中的完整包导出需先暂停或停止。

**加载prepared checkpoint后继续。** 本版GUI没有这项操作；“载入配置”“载入结果”均不是checkpoint续算入口。

### 科学范围

默认实例是来源受限的小ROI有效动力学原型，数值收敛不等于生理验证。S/H2共享kinetics、BC/AC/RGC与部分rod下游参数、HC接触人口、arbor外推、生成器mixing及有限外部回路闭合仍有未标定范围；随机稳态统计也未确立。

中央实例执行34组件而旧外围实例为39组件，差别是LM>20deg外围物理参考链在中央ROI不适用；20个必需机制层仍执行。没有将外围参考移植为中央或S-cone校准，也没有恢复SC或DeepGaze实验。
