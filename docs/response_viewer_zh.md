# 当前 69#6 内部状态浏览

双击项目根目录 `run_retina_gui.cmd`，默认进入现有 Tk 软件中的“内部状态浏览”。默认读取 `reports/GIN_69_6_HC2_BC1_SUPPORT_V2/current_ac_source`，不会运行模型。

1. 顶部“打开…”选择当前研究目录或 `current_ac_source`，在“目标 RGC”中选择对象。“导出…”保存当前图；其他结果回放与数据来源保留在“更多”中。69#6 有完整 RGC 轨迹，其他对象只显示其真实记录。
2. “分层状态”顶部显示输入刺激视频，与底部播放、暂停、滑块和跳转共用时间轴，并标注真实帧时间、零起始帧索引和原始分辨率。下方切换细胞类型并点击空间点，左侧集中显示选中对象、坐标角色和成员表示；长 ID 采用缩略显示，“复制 ID”获取完整标识。选择变量后打开响应曲线。鼠标在层内滚轮缩放，按 R/r 重置当前悬停层；其他层不受影响。输入框内键入 R 不会重置图。
3. 左侧“时间范围 / s”控制曲线区间；“短窗口”进入 **5.0–5.5 s** 连续跨层响应，“全片”恢复完整时间范围。短窗播放到末尾暂停，再次播放从起点开始，可将速度设为 0.1× 慢看。底部仍可拖动或输入秒数跳转；跳到窗外恢复全片浏览。窗外原快照保留实际时间，不补造缺失数据。

5. “导出…”或曲线窗口的导出按钮保存 PNG，内嵌来源身份与时间信息。默认目录为 `semireport/2026-11-06-内部状态可视化`，可在保存对话框另选。界面的简短标题与缩略 ID 不替代导出中的完整来源信息。
6. 右上角选择中文、日本語、English。当前内部状态窗口、图表、提示和导出使用所选语言，细胞 ID、科学变量与单位保持原样；切换语言保留所选对象、时间、缩放。
7. 底部“记录覆盖”随当前选中对象和变量更新，区分连续记录、保存快照和未记录区。点击覆盖条可以跳转；左侧也可直接选择保存快照。目标 69#6 的已保存完整变量可覆盖 0–45 s；上游连续状态通常只有 5–5.5 s，其他时段按实际快照显示。覆盖条不把整个结果目录的可用时间误当作每个对象的记录范围；“显示说明”保留单位、缺失记录和操作提示。

软件启动时启用 Windows 系统 DPI 支持，图表按画布实际像素绘制，文字、线条和点选位置随显示缩放同步调整。更新后需要重开软件；本机 150% 缩放使用约 144 DPI 绘制。刺激源本身为 256×256 像素，预览保持原比例，不生成额外图像细节。移动到不同缩放比例的另一台显示器仍可能由 Windows 缩放，此次没有增加跨显示器动态适配。

# 完整响应的桌面分层回放

在内部状态窗口点击“其他结果回放”。Cell6 既有回放保留在该窗口左侧按钮中；原模拟设置界面也有“完整响应 / 视频分层回放”入口。

命令行启动：

```powershell
& '.\.venv\Scripts\python.exe' -B -X utf8 -m retina_platform --response-replay --result 'reports\result_packages\retina_113_4s_298fa2ef1524.response.zip'
```

## 使用

1. 选择“导入结果ZIP”，直接选择生成的结果包。也可导入已完成运行目录或其 JSON manifest。
2. 选择 near / far，再选择 RGC 类型和实际组 ID。默认只显示该目标的真实连接祖先；反馈、电耦合会扩大祖先范围。勾选“全部patch作灰色对照”可看其余组。
3. 底部播放、暂停、逐视频帧步进、拖动和速度共用物理时间轴。视频来自包内的原始 RGB 帧。本例为113.AVI原视频的0–4秒、120帧，而非整个14.9秒。
4. 点击任一层的点，查看组 ID、类型、坐标及坐标语义、代表成员数、当前状态与单位。“细胞 / 状态详情”提供完整内容；“响应曲线”独立打开，能切换实际保存的字段。
5. 左栏可滚动。窗口缩小时播放条固定保留，各层说明随宽度换行。

导入刺激视频时先用完整文件 SHA 匹配现有结果。当前已有113.AVI的对应4秒结果。没有匹配响应时清空旧热图并提示“需要计算”；不会静默启动长计算，也不会伪造热图。任意新视频的物理输入定义与计算仍由对应计算入口负责，本回放器不发明这些参数。

## 一个ZIP包含什么

版本化 `manifest.json` 按以下类别绑定相对路径、SHA、大小、用途、字段单位、时间、组身份、范围和缺失项：

- `stimulus/`：120帧原始RGB及帧率、曝光、时间定义；不把有损预览当模型输入。
- `responses/near`、`responses/far`：完整原始NPZ时间分块、原身份、单位、事件和数值/资源结果。
- `cells/`：实际局部组ID、成员数、坐标/角色和非零连接CSR，包括有效AC池与HC同型耦合。
- `provenance/`：参数、来源、初始化和选择身份。历史绝对路径只作来源描述，回放不沿这些路径取文件。
- `reports/`、`logs/`：必要报告、指标、曲线和执行日志，包括原失败记录。

示例ZIP约1.49GB，主要是保留原字节身份的已压缩响应NPZ；没有打入vendor、全工程或无关光学缓存。包用于完整已保存响应的回放，不是完整可恢复模型checkpoint。

导入不执行脚本、不加载pickle；拒绝绝对路径、路径穿越、大小写重复路径、符号链接、哈希不符和超限解压。限制为4096文件、总8GiB、单文件2GiB，NPZ内部数组另有限额。导出先完成临时文件，再原子改名；已有包不会覆盖，原始结果不会删除。
